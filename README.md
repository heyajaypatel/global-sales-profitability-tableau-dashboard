# Global Sales Performance & Profitability Dashboard

## Project Overview

This project focuses on analyzing global sales performance and profitability across regions, countries, product categories, and customer segments using Tableau. The dashboard provides actionable insights to help businesses monitor revenue growth, improve profitability, and optimize sales strategies.

---

## Objective

The objective of this project is to:

* Monitor global sales performance
* Track profitability across regions and products
* Analyze customer segments and sales trends
* Identify high-performing markets
* Support strategic business decision-making

---

## Tools Used

* Tableau Public
* Microsoft Excel
* Sales Analytics
* Business Intelligence
* Data Visualization
